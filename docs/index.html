KuniGram iOS • Python Plugins Engine

Документация KuniGram

Кастомный iOS-клиент на базе Telegram-iOS со встроенным ядром Python-плагинов, полным доступом к Telegram API, внешним серверам, камере и режимом маскировки.

Обзор возможностей

Ядро Плагинов (Python)

Загружайте .py файлы из Файлов или буфера обмена, включайте/выключайте переключателем, смотрите логи и удаляйте в один тап.

Полный Telegram API

Отправка, редактирование, удаление, пересылка сообщений, реакции, фото, файлы, получение чатов и профиля.

Внешние серверы и WebSocket

Встроенные модули api.net и requests для HTTP GET/POST/PUT/DELETE и постоянных WebSocket-подключений.

Камера, Медиа и Маскировка

Съёмка фото через api.camera.take_photo(), ресайз, сохранение в галерею и переключение иконки под Telegram.

Быстрый старт

Откройте Настройки → KuniGram → Ядро Плагинов. Каждый плагин — это обычный .py файл с метаданными в начале файла: 

__id__ = "hello_kunigram"
__name__ = "Hello KuniGram"
__author__ = "YourName"
__version__ = "1.0.0"
__description__ = "Пример первого плагина для KuniGram"

def on_load(api):
    api.log("Плагин запущен!")
    api.ui.show_toast("Hello from KuniGram Python!")

def on_command(cmd, args, msg):
    if cmd == "ping":
        api.tg.send_message(msg["peer_id"], "Pong! 🍑", reply_to=msg["message_id"])

Сеть и WebSocket (api.net / requests)

import requests
import json

resp = requests.post(
    "https://api.example.com/webhook",
    json={"event": "ping", "user": "kunigram"},
    headers={"Authorization": "Bearer TOKEN"}
)
if resp["status"] == 200:
    data = resp["json"]
    api.log(f"Server replied: {data}")

# WebSocket
ws = api.net.ws_connect("wss://echo.websocket.events")
api.net.ws_send(ws, json.dumps({"hello": "server"}))
api.net.ws_close(ws)

Камера и Медиа (api.camera / api.media)

# Сделать фото с основной или фронтальной камеры ("back" / "front")
photo = api.camera.take_photo(camera="back")
if "path" in photo:
    # Отправить сразу в чат Telegram
    api.tg.send_photo(peer_id, photo["path"], caption="Снято из плагина KuniGram!")
    # Или сохранить в Фотоплёнку
    api.media.save_to_gallery(photo["path"])

UI, Логи и Хранилище (api.ui / api.storage)

  • api.ui.show_toast(text) — показать всплывающее уведомление внутри Telegram
  • api.ui.show_alert(title, message) — показать диалоговое окно
  • api.storage.set(key, value) / api.storage.get(key, default=None) — персистентное JSON-хранилище плагина
  • api.log(text) / print(...) — запись в консоль логов плагина

Примеры готовых плагинов

1. Команда .snap — сделать фото и отправить в чат

__id__ = "quick_snap"
__name__ = "Quick Snap"
__author__ = "KuniGram"
__version__ = "1.0"
__description__ = "Делает фото по команде .snap front / .snap back"

def on_command(cmd, args, msg):
    if cmd == "snap":
        cam = "front" if "front" in args else "back"
        res = api.camera.take_photo(camera=cam)
        if "path" in res:
            api.tg.send_photo(msg["peer_id"], res["path"], caption="📸 KuniGram Snap")
        else:
            api.ui.show_toast("Camera error: " + str(res.get("error", "")))

2. Мост с внешним сервером (.ask)

__id__ = "server_bridge"
__name__ = "Server Bridge"
__author__ = "KuniGram"
__version__ = "1.0"
__description__ = "Отправляет запрос на ваш сервер и отвечает в чат"

import requests

def on_command(cmd, args, msg):
    if cmd == "ask":
        api.tg.set_typing(msg["peer_id"])
        r = requests.post("https://your-server.example.com/ask", json={"prompt": args})
        if r["status"] == 200 and r["json"]:
            answer = r["json"].get("answer", "Empty response")
            api.tg.send_message(msg["peer_id"], answer, reply_to=msg["message_id"])

Дополнительные настройки: Маскировка под Telegram

В самом низу меню KuniGram находится раздел Дополнительные настройки с переключателем Маскировка под Telegram.

  • По умолчанию приложение называется KuniGram и использует рисованную иконку персика на белом фоне.
  • При включении маскировки иконка приложения на домашнем экране iPhone немедленно меняется на стандартную синюю иконку Telegram через UIApplication.setAlternateIconName.
  • Ограничение iOS: система Apple не позволяет менять CFBundleDisplayName (подпись под иконкой на рабочем столе) динамически во время работы без пересборки/переподписи пакета.
