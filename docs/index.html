KuniGram iOS • Python Plugins Engine v1.0

Полная документация KuniGram

Кастомный iOS-клиент на базе Telegram-iOS со встроенным ядром Python-плагинов, отправкой Star Gifts и коллекционных подарков, полным Telegram API, внешними HTTP/WebSocket-запросами, камерой и маскировкой под Telegram.

Обзор возможностей

Ядро Плагинов (Python)

Импортируйте .py файлы из Файлов или вставляйте код из буфера обмена. Включайте/выключайте переключателем, смотрите логи и удаляйте в один тап.

Подарки и Telegram API

Получение каталога подарков, отправка обычных и коллекционных Star Gifts, пересылка, конвертация в звёзды, сообщения, фото, файлы и реакции.

Внешние серверы и WebSocket

Встроенные модули api.net и requests для HTTP GET/POST/PUT/DELETE и постоянных WebSocket-подключений к любым вашим серверам.

Камера, Медиа и Маскировка

Съёмка фото через api.camera.take_photo(), ресайз, сохранение в галерею и переключение иконки под Telegram в Дополнительных настройках.

Быстрый старт

Откройте Настройки → KuniGram → Ядро Плагинов. Нажмите «Загрузить плагин (.py)» или «Вставить плагин из буфера». После загрузки плагин сразу активируется и вызывает on_load(api). 

__id__ = "hello_kunigram"
__name__ = "Hello KuniGram"
__author__ = "YourName"
__version__ = "1.0.0"
__description__ = "Пример первого плагина для KuniGram"

def on_load(api):
    api.log("Плагин запущен!")
    api.ui.show_toast("Hello from KuniGram Python!")

def on_command(cmd, args, msg):
    if cmd == "ping":
        api.tg.send_message(msg["peer_id"], "Pong! 🍑", reply_to=msg["message_id"])

Метаданные плагина

Указывайте метаданные в начале .py файла — они отображаются в списке плагинов и используются для хранения настроек:

Поле Обязательно Описание
__id__НетУникальный идентификатор плагина и его JSON-хранилища
__name__НетОтображаемое имя в списке плагинов
__author__НетИмя автора (отображается под названием)
__version__НетВерсия плагина, например 1.2.0

Подарки Telegram (api.tg.*_star_gift*)

Полноценный API для работы с подарками Telegram: получение каталога, отправка обычных подарков за Stars, покупка коллекционных подарков по slug, пересылка и конвертация.

Метод Параметры и возврат
tg.get_star_gifts() Возвращает list[dict] доступных подарков: id, price, convert_stars, is_limited, remains, total (или slug, title, number, is_unique).
tg.send_star_gift(peer_id, gift_id, text="", hide_name=False, upgrade=False) Отправляет подарок gift_id пользователю peer_id с подписью text. Возвращает {"ok": True/False, "error": ...}.
tg.buy_star_gift(peer_id, slug, text="", hide_name=True) Покупает и отправляет коллекционный (уникальный) подарок по его slug. Возвращает {"ok": bool}.
tg.transfer_star_gift(from_peer, message_id, to_peer) Передаёт ваш подарок из сообщения message_id другому пользователю to_peer. Возвращает bool.
tg.convert_star_gift(peer_id, message_id) Конвертирует полученный подарок в звёзды Telegram. Возвращает bool. 
# Пример: получить список лимитированных подарков и отправить самый дешёвый
gifts = api.tg.get_star_gifts()
for g in gifts:
    if g.get("is_limited") and g.get("remains", 0) > 0:
        res = api.tg.send_star_gift(
            peer_id=123456789,
            gift_id=g["id"],
            text="Подарок из KuniGram 🍑",
            hide_name=False
        )
        api.log(f"Gift result: {res}")
        break

Сеть и WebSocket (api.net / requests)

Поддерживаются синхронные HTTP-запросы (get, post, put, delete, request) и постоянные WebSocket-соединения.

Метод Параметры и возврат
requests.get(url, params={}, headers={}, timeout=20)Возвращает {"status": int, "text": str, "json": Any, "headers": dict}
requests.post(url, json=None, data=None, headers={})Отправляет JSON или raw body, возвращает тот же dict ответа
requests.put(...) / requests.delete(...)HTTP PUT и DELETE запросы
api.net.request(method, url, headers={}, body=None, timeout=20)Произвольный HTTP-метод
api.net.ws_connect(url)Открывает WebSocket и возвращает ws_id
api.net.ws_send(ws_id, text) / api.net.ws_close(ws_id)Отправляет текст в сокет / закрывает соединение

Камера и Медиа (api.camera / api.media)

Метод Описание
api.camera.take_photo(camera="back")Делает снимок с "back" или "front" камеры. Возвращает {"path", "width", "height", "base64"}.
api.media.save_to_gallery(path)Сохраняет изображение по path в Фотоплёнку iPhone.
api.media.resize_image(path, width, height)Изменяет размер изображения и возвращает путь к новому JPEG-файлу.

UI, Логи и Хранилище (api.ui / api.storage)

  • api.ui.show_toast(text) — показывает всплывающий баннер поверх интерфейса
  • api.ui.show_alert(title, message) — открывает системное диалоговое окно Telegram
  • api.storage.set(key, value) / get(key, default=None) / delete(key) / keys() — персистентное JSON-хранилище в Documents/KuniGram/Storage/<id>.json
  • api.log(text) / print(...) — пишет в консоль логов плагина (доступна в карточке плагина)

Встроенный Python и модули

Интерпретатор KuniPyRuntime поддерживает функции (def, return, значения по умолчанию), циклы (for, while, break, continue), условия (if/elif/else), try/except, f-строки, списки, словари и стандартные модули:

  • json: dumps(obj), loads(str)
  • time: time(), sleep(sec)
  • math: pi, e, sqrt, floor, ceil
  • random: random(), randint(a, b), choice(seq)
  • base64: b64encode(str), b64decode(str)
  • hashlib: sha256(str)
  • Встроенные функции: len, str, int, float, bool, range, abs, print

Примеры готовых плагинов

1. Отправка подарка по команде .gift

__id__ = "gift_sender"
__name__ = "Star Gift Sender"
__author__ = "KuniGram"
__version__ = "1.0"
__description__ = "Отправляет подарок по команде .gift  <текст>"

def on_command(cmd, args, msg):
    if cmd == "gift":
        gifts = api.tg.get_star_gifts()
        if len(gifts) == 0:
            api.ui.show_toast("Каталог подарков пуст")
            return
        gift_id = gifts[0]["id"]
        res = api.tg.send_star_gift(msg["peer_id"], gift_id, text=args)
        if res.get("ok"):
            api.ui.show_toast("Подарок отправлен! 🎁")
        else:
            api.ui.show_toast("Ошибка: " + str(res.get("error", "")))

2. Команда .snap — сделать фото и отправить в чат

__id__ = "quick_snap"
__name__ = "Quick Snap"
__author__ = "KuniGram"
__version__ = "1.0"
__description__ = "Делает фото по команде .snap front / .snap back"

def on_command(cmd, args, msg):
    if cmd == "snap":
        cam = "front" if "front" in args else "back"
        res = api.camera.take_photo(camera=cam)
        if "path" in res:
            api.tg.send_photo(msg["peer_id"], res["path"], caption="📸 KuniGram Snap")
        else:
            api.ui.show_toast("Camera error: " + str(res.get("error", "")))

3. Мост с внешним сервером (.ask)

__id__ = "server_bridge"
__name__ = "Server Bridge"
__author__ = "KuniGram"
__version__ = "1.0"
__description__ = "Отправляет запрос на ваш сервер и отвечает в чат"

import requests

def on_command(cmd, args, msg):
    if cmd == "ask":
        api.tg.set_typing(msg["peer_id"])
        r = requests.post("https://your-server.example.com/ask", json={"prompt": args})
        if r["status"] == 200 and r["json"]:
            answer = r["json"].get("answer", "Empty response")
            api.tg.send_message(msg["peer_id"], answer, reply_to=msg["message_id"])

Дополнительные настройки: Маскировка под Telegram

В самом низу меню KuniGram находится раздел Дополнительные настройки с переключателем Маскировка под Telegram.

  • По умолчанию приложение называется KuniGram и использует рисованную иконку персика на белом фоне.
  • При включении маскировки иконка приложения на домашнем экране iPhone немедленно меняется на стандартную синюю иконку Telegram через UIApplication.setAlternateIconName.
  • Ограничение iOS: система Apple не позволяет менять CFBundleDisplayName (подпись под иконкой на рабочем столе) динамически во время работы без пересборки/переподписи пакета.
